Play with a Switch 2 Pro Controller

A Mac can't use the Switch 2 Pro Controller by itself. It doesn't appear in Bluetooth, and plugged in over USB it stays silent. This page wakes it up so Chrome can read it, and then you can play Super Grandmasters with it. Nothing to install.

What you need

  • ChromeSafari and Firefox can't talk to the controller over USB.
  • A USB-C data cableThe one that came with the controller works. Some charge-only cables don't.
  • The controller, plugged inStraight into the computer, not through a hub, to start.
This browser can't use the controller over USB. Open this page in Chrome.

Set it up

  1. Plug the controller in

    Use the USB-C cable, controller to computer.

  2. Wake it up

    Click the button, choose Pro Controller in Chrome's list, and press Connect. Chrome only asks the first time.

  3. Check it works

    Press any button. The buttons below light up as you press them, and the dots follow the sticks.

    Waiting for the controller…

    If nothing appears, press a button on it.

    Left stick
    Right stick

  4. Play

    Open the game in a new tab, then press + on the controller. It joins as Player 1. You can change what each button does under Controls.

If something's off

Chrome's list is empty

Chrome can't see the controller. Try the cable that came with it, another port, and unplugging and plugging it back in. A cable that only charges won't work.

"Access denied" or "Unable to claim interface"

Another app is holding the controller. Quit Steam, emulators and any controller utility, unplug the controller, plug it back in, and try again.

It stopped working after I unplugged it

The controller forgets the wake-up when it's unplugged. Plug it back in and this page (or the game's Controls screen) wakes it again, without asking Chrome's list a second time.

Buttons feel mixed up

In the game, open Controls and set each button to what you want. Your choices are saved in that browser.

Windows or Linux

This is made for Chrome on a Mac. On other systems Chrome may need a USB driver for the controller before this works.
