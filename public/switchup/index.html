SwitchUp

A Nintendo Switch Pro Controller as a mouse, trackpad and remote for the Mac. Built for YouTube from the couch.

Download SwitchUp v1.0 · macOS 14 or later · Apple Silicon & Intel · notarized by Apple
Setup
  1. InstallUnzip the download and drag SwitchUp into Applications, then open it. It lives in the menu bar as a controller icon.
  2. Pair the controllerHold the small sync button on top of the Pro Controller until the lights run, then select it in System Settings › Bluetooth.
  3. Allow AccessibilitySystem Settings › Privacy & Security › Accessibility › switch SwitchUp on. This lets it move the pointer, click and press keys.
  4. Free up the Home buttonSystem Settings › Game Controllers › Controller Shortcuts › turn off “Enable controller shortcuts”. Otherwise Home also opens Apple’s Games app.

SwitchUp opens a setup window on first launch with a button for each step.

Tuning

Every button can be remapped, and the pointer and scroll response curves are adjustable to the hundredth: speed, exponent, dead zones, smoothing, momentum. Open the menu-bar icon › Settings. The menu itself lists the current layout.

Dictation needs to be switched on in System Settings › Keyboard › Dictation. Other controllers that macOS recognizes also work; the Home button is read directly only on the Switch Pro Controller.
